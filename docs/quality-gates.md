# Quality Gates

A creator run advances only when it passes the gate appropriate to its current stage.

| Gate | Pass condition |
|---|---|
| Brief | Audience, format, genre, tone, and deliverable are explicit |
| Concept | Central contradiction and visual thesis are memorable |
| Canon | Character anchors, world rules, and forbidden changes are recorded |
| Story | Each beat changes desire, knowledge, or consequence |
| Layout | Reading order and reveal timing work without prose explanation |
| Visual | Silhouette, palette state, setting, and motif continuity hold |
| Lettering | Voice, hierarchy, legibility, and balloon flow hold |
| Continuity | References, seeds, versions, and unresolved mismatches are tracked |
| Publishing | Export dimensions, accessibility, credits, and provenance are complete |

## Reader simulation

- What do I notice first?
- What question am I carrying into the next panel?
- Where did I infer rather than get told?
- Which image becomes more disturbing after the reveal?
- Can I identify every speaker?
- Does the final beat create a permanent new rule?

## Red flags

- Generic fantasy ornament replacing character-specific evidence.
- Transformations adding random horns, wings, or armor without psychological cause.
- Too many motifs competing in one scene.
- Dialogue explaining what the image already proves.
- A reveal that changes lore but not behavior.
- Generated assets with no seed, prompt version, or reference trace.
