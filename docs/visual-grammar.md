# Visual Grammar and Story Flow

## Page mental states

| Page type | Reader experience | Signature choices |
|---|---|---|
| Evidence | Inspect and compare | Insets, labels, repeated angles, stable grid |
| Temptation | Desire and approach | Beautiful object, narrowed field, warm accent, inviting negative space |
| Possession | Loss of agency | Border rupture, wrong perspective, invasive lettering, body repetition |
| Consequence | Reinterpretation | Echoed image, altered palette, missing object, aftermath silence |
| Codex | Interpret and doubt | Marginalia, diagrams, contradictions, partial redactions |

## Genre rhythm formulas

- Horror: ordinary procedure → anomaly → denial → proof → silence.
- Mystery: clue → false theory → contradiction → hidden witness → cost of knowing.
- Transformation: bodily inconvenience → private concealment → public failure → new rule.
- Comedy: confident plan → literal consequence → escalation → embarrassed correction.
- Punk satire: official claim → material contradiction → public performance → refusal.

## Page-turn and scroll rules

- Put the question before the turn and the answer after it.
- Use a blank or nearly blank beat before an irreversible image.
- Never spend a reveal and its emotional consequence in the same visual beat unless speed is the point.
- In vertical formats, vary gap length: short for urgency, long for dread, irregular for a broken mind.
- If a motif repeats, change one property each time: position, scale, color, owner, or meaning.

## Mandatory episode ingredients

Every episode must contain:

1. A mundane action that establishes the baseline.
2. An impossible behavior that can be mistaken for coincidence.
3. A private lie told by a character to preserve the old world.
4. An avoidable decision that activates agency.
5. A consequence that remains true after the episode ends.
6. One image whose meaning changes when the final page is read.
