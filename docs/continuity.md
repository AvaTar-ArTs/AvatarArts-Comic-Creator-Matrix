# Continuity and Canon

## Canon entities

The storyworld model should support:

- characters
- creatures
- factions
- realms
- locations
- relics
- curses
- visual motifs
- timelines
- episodes
- panels
- assets
- publications
- contradictions

## Character continuity

Lock:

- silhouette
- face and hair
- costume construction
- signature props
- color-state behavior
- expression vocabulary
- transformation rules
- current injuries or changes
- relationship state

## Visual rules

For the Crimson Curse Master:

- tall, narrow silhouette
- asymmetrical scarlet-black hat
- pale beard with one crimson section
- incomplete seven-point collar mark
- poison quill
- left hand gloved, right hand altered
- one displaced object in every major scene

Transformation must alter biography into anatomy. Do not add arbitrary horns, wings, armor, or tentacles without a story reason.

## Narrative rules

Every episode must include:

- one mundane action
- one impossible behavior
- one private lie
- one avoidable decision
- one persistent consequence
- one image that changes meaning on rereading

Recommended progression:

```text
ordinary procedure
→ small anomaly
→ investigation
→ personal recognition
→ false control
→ moral choice
→ curse-specific consequence
→ new permanent rule
```

## Visual QA

Check every output at:

- full size
- thumbnail
- mobile width
- print size
- grayscale
- text-free crop
- neighboring-panel context

## Canon QA

Check:

- character identity
- costume state
- props and relics
- spatial continuity
- palette state
- sigil state
- timeline
- power limits
- consequences
- intentional contradictions

Mystery should be ambiguous by design, never inconsistent by accident.
