# AvatarArts Comic Creator Matrix Roadmap

## Phase 1: Explore

- Build the brief, creator mode, genre, format, and audience selectors.
- Run brainstorm, research, lore, psychology, and visual thesis agents.
- Produce a storyworld packet and contradiction map.

## Phase 2: Create

- Compile episode beats and panel records.
- Resolve character and realm references.
- Generate images through provider adapters.
- Compose pages, webtoon scrolls, lettering, and export manifests.

## Phase 3: Refine

- Run visual, canon, lettering, continuity, and reader simulation gates.
- Apply colorization, denoise, and upscale where appropriate.
- Preserve prompt, seed, asset, and reviewer provenance.
- Export comic, manga, graphic novel, webtoon, video storyboard, and archive bundles.

## Priority order

1. Canonical storyworld and panel schemas.
2. Reference-aware generation and provenance.
3. Page and lettering composition.
4. Continuity and quality gates.
5. Creator-specific adapters.
6. Animation and publishing extensions.
