# Creator Modes

The same canon can be translated into different publication grammars without losing identity.

| Mode | Layout grammar | Best use |
|---|---|---|
| Manga page | Right-to-left print rhythm, close-ups, silence, emotional pacing | Interior conflict, ritual, possession |
| Western comic page | Impact panels, splash pages, dynamic action | Confrontation, spectacle, public myth |
| Webtoon scroll | Vertical pacing, negative space, scroll reveals | Suspense, transformations, cliffhangers |
| Graphic-novel spread | Deliberate page composition and environmental continuity | Realm reveals and journeys |
| Occult codex | Diagram, artifact, annotation, correction, contradiction | Lore and forbidden history |
| Punk zine | Collage, rough lettering, irregular borders, satire | Rebellion, propaganda, corrupted institutions |
| Album-art sequence | One dominant image, title system, symbolic compression | Music, campaigns, character identity |
| Animated storyboard | Shot size, camera movement, timing, transition | Video and music-video adaptation |

## Format selection

Choose format by emotional objective:

- **Dread:** sparse panels, long gutters, delayed reveal
- **Action:** compressed panels, diagonals, impact splash
- **Mystery:** evidence grid, inserts, contradiction
- **Transformation:** small-to-large escalation, border violation
- **Aftermath:** repeated angles, negative space, minimal text
- **Myth:** wide environmental panels, ceremonial pacing
- **Comedy:** clean setup, reaction panel, reversal
- **Punk satire:** collage, intrusive type, broken hierarchy

## Layout rules

1. Panel geometry must reflect mental state.
2. Do not use asymmetry everywhere; make it meaningful.
3. Reserve page turns and scroll gaps for reveals.
4. Every panel needs a narrative job.
5. Text placement is part of composition, not post-production decoration.
6. A visual motif should recur with changed meaning.
7. The final panel must create a new question or consequence.
