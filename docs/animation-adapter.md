# Animation and Video Adapter

Animation extends comic grammar; it does not replace it. A panel remains the keyframe, and motion reveals what the gutter withheld.

## Panel-to-motion mapping

- Evidence: slow camera inspection, no ornamental movement.
- Temptation: object moves before the character reacts.
- Possession: camera obeys the wrong subject, text drifts, loop timing becomes irregular.
- Consequence: repeat an earlier shot with one changed physical fact.
- Codex: diagram layers separate, annotations arrive late, archival sound is dry and close.

## Reveal discipline

- Start from a still composition.
- Animate only one causal change per beat.
- Preserve silhouette and palette anchors.
- Use sound as a second lettering system.
- End on a changed rule, not merely a dramatic pose.

## Delivery

The adapter should export a storyboard, shot list, motion notes, asset references, and a provenance record before rendering video.
